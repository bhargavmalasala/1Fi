# 1Fi Marketplace

A frontend implementation of the **1Fi Marketplace**, integrated into the existing Shop experience as part of the **1Fi SDE Intern Assignment**.

The project focuses on extending the existing 1Fi experience while maintaining consistency in **UI, navigation, interactions, and overall user experience**.

## ✨ Features

* 🛍️ Browse products with product images, pricing and details
* 🔎 Search, category filtering and price sorting
* 🎨 Product variant selection
* 💳 Multiple EMI plans with interactive selection
* 🚀 Proceed with the selected EMI plan
* ⚡ Loading, error and empty states
* 📱 Responsive design for desktop and mobile
* 🧩 Reusable React components
* 🔌 Structured mock API/data layer for products and EMI information

## 🛠️ Tech Stack

**React · JavaScript · Vite · CSS**

## 📂 Project Structure

```text
src/
├── components/
├── marketplace/
│   ├── api.js
│   └── products.js
├── pages/
└── App.jsx
```

Product and EMI data are separated from the UI through a dedicated data/API layer, keeping the implementation maintainable and ready for future backend integration.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```
